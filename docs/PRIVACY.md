# Privacy policy — 3ahd (عهد)

Last updated: 2026-09-29

3ahd is a free, open-source desktop app for prayer times. It is built so that your data stays on your computer.

## What 3ahd does not do

- No accounts, no sign-in.
- No analytics, no telemetry, no crash reporting to third parties.
- No advertising and no tracking of any kind.

## Data stored on your computer

Settings, saved locations, prayer-time offsets, an imported official timetable, Quran bookmarks and last-read
positions, today's adhkar counters, custom adhan files and downloaded books are stored only in the app's data
folder on your computer. You can export, import or erase all of it in Settings → Privacy & data.

## When 3ahd uses the network

3ahd works fully offline. It connects to the internet only for these optional features, each of which can be
turned off in Settings → Privacy & data:

| Feature | Service | What is sent | When |
|---|---|---|---|
| Online place search | OpenStreetMap Nominatim | The text you typed | Only when you press "Search online" |
| Map (location pin, qibla line) | OpenStreetMap tiles | The map area being shown | Only while a map is on screen |
| Library downloads | IslamHouse (api3.islamhouse.com) | The book requested | Only when you download a book |
| Tafsir downloads | Quranic Universal Library | The tafsir requested | Only when you download a tafsir |
| Update check (GitHub builds only) | GitHub | App version | Once a day, if enabled |

Your location is never sent anywhere automatically. It leaves your computer only if you search for a place
online or open the online map, and then only as described above.
